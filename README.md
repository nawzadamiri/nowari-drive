# Nowari Drive

A relaxing drive, walk and flight through a painted miniature of Tampere, built from public data.

Play: https://nawzadamiri.github.io/nowari-drive/ (also `?city=kaleva` and `?city=hervanta`)

This repository holds only the built game.

Map data © OpenStreetMap contributors (ODbL) · Elevation and aerial photos © National Land Survey of Finland (CC BY 4.0) · Building data and 3D city model © City of Tampere · Signs, lights and stops © Fintraffic / Väylävirasto, Digiroad (CC BY 4.0)
